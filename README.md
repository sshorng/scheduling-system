# 排課系統（HTML＋GAS 架構）開發計畫與說明文件

本專案為取代舊有欣河系統之國中排課系統，前端為純 HTML＋CSS＋JS 單頁應用，後端使用 Google Apps Script（GAS）連結 Google 試算表作為資料庫，且需完全對齊舊版「調代課系統」的資料格式。

---

## 一、專案狀態（2026-08-23 最新進度）

### 🟢 已經完成的功能

1. **檔案架構與模組化**：
   - 前端：`index.html`、`style.css`、`app.js`、`word-export.js`。
   - 後端：`Code.gs`（GAS Web App REST API）。
2. **直觀兩欄式對照與雙向連動**：
   - 兩欄式課表：左欄檢視「班級課表」，右欄同步檢視「教師課表」。
   - 點擊待排卡片中的教師/班級標籤，對側課表自動同步切換。
   - 樂觀 UI 0ms 拖曳體驗：拖曳、移動、Shift 互調、右鍵清除均本地即時寫入＋背景非同步寫入 GAS。
3. **衝突偵測與軟硬性排課限制**：
   - **硬性阻擋**：教師衝堂、科目已達同時開課班數上限、科目禁排時段、教師不排課時段。
     - **手動調課警告**：教師連堂超過設定上限時，手動排課會先顯示警告，確認後可強制寫入；此項不列入手動整批寫入的硬稽核。自動排課與唯讀候選課表稽核仍維持硬限制。
4. **全站智慧教師搜尋輸入框 (`initTeacherCombobox`)**：
   - 全頁所有教師欄位（教師課表、班級導師、配課教師、批次配課 Modal）統一升級為無下拉箭頭、高度 36px 齊平、帶 `✖` 清空鈕的搜尋輸入框。
   - 點擊/獲得焦點即刻彈出全校名單，打字或輸入代號/姓名即時動態篩選。
5. **全新 3 大單一主題【批次配課控制台】**：
   - 🏫 **按班級/年級配課**：選目標班級/年級 ➡️ 直覺呈現在地化全班科目與教師搜尋欄，集中順手填寫。
   - 📚 **按科目配課**：選科目 ➡️ 展開全校/各年級班級核取框（可細部單獨勾選/全選）＋ 「⚡ 全年級一鍵快速指定教師」。
   - 👩‍🏫 **按教師配課**：選教師與科目 ➡️ 快捷勾選多個班級進行指派。
6. **📄 官方 Word 課表匯出 (`word-export.js`)**：
   - 支援「班級課表」與「教師課表」兩大分頁獨立批量匯出為 `.docx`（每班/每師一頁）。
     - **第八節單雙週拆欄**：自動解析單雙週課程，於範本中帶入 `{d1p8s}`（單）與 `{d1p8d}`（雙）佔位符拆欄顯示。
      - 午休有課時保留班級課表的節次欄；第八節單／雙週依 Word grid 寬度平均切分，九年級無本土語時隱藏空白配課列而不改變表格 grid。
      - 班級與教師 Word 課表固定欄寬；協同教師的超鐘點標記依教師個別保存，不再共用同一格的超鐘點狀態。
     - 配色規則支援星期與第 1 至第 8 節範圍，並套用至 Word 課表特殊列與第八節拆欄。
     - 單格指派視窗開啟既有課程時，會自動選取同班同科配課，帶入主要教師與協同教師標籤，避免舊課表教師清單覆蓋配課設定。
7. **👥 綁班群組（共同上課）**：
   - 支援多班共同上課（如體育合班、藝能合班），拖曳某一班課表時，綁定班級自動同步移動。
8. **🤖 智慧自動排課引擎 (MRV Heuristic Auto-Scheduler)**：
   - 自動避開衝堂、不排課時段、同時班數限制與科目禁排/必排時段。
    - 支援核心學科優先排於上午、同科目每天最多 1 節、連堂課自動併排等智慧規則。
9. **相容性匯出**：
     - 匯出格式與舊有調代課系統要求完全一致（學期代號、教師 Email、星期、節次、課堂屬性等）。
     - 額外輸出「特殊標記」欄，保留併班、綁課、預排；抽離、超鐘點、實支則保留於「課堂屬性」。多教師課程拆列時會產生穩定唯一的課表 ID。
11. **綁班鎖定與手動連堂（v1173）**：
    - 綁班右鍵鎖定／解鎖會以同一個時段的完整綁班成員為原子單位，不允許留下部分鎖定。
    - 手動綁班整組寫回帶有 `manualSoftWarnings` 標記；主教師衝堂與科目禁排仍直接拒絕，教師互斥、連堂、教室容量、科目同時班數等衝突先提醒，確認強制後可寫入。

## 二、完整技術規劃與需求規格

### 技術架構
- **前端**：純 HTML5 + CSS3 + Vanilla JavaScript（`index.html`, `style.css`, `app.js`, `word-export.js`）
- **後端**：Google Apps Script (`Code.gs` Web App REST API)
- **資料庫**：Google 試算表（繁中工作表名稱自動建表）

### 資料模型（Google 試算表工作表）

| 工作表名稱 | 欄位 | 說明 |
|-----------|------|------|
| 班級 | 班級代碼、年級、班級名稱、導師代碼、班級類型、是否虛擬班、雙語課堂數 | 例：701 七年一班 |
| 教師 | 教師姓名、Email、任教科目、職稱、最大連堂節數、基本鐘點、減授原因 | 導師依職稱判定 |
| 教室 | 教室代碼、名稱、類型 | （⚠️ 待開發）普通教室／專科教室 |
| 科目 | 科目代碼、科目名稱、每週節數、同時最多班數、連堂節數、最多連日 | |
| 配課設定 | 配課ID、班級代碼、科目代碼、教師代碼、課程屬性、每週節數、備註 | 哪位老師教哪班哪科；課程屬性可設為「預排」 |
| 課表 | 課表ID、班級代碼、星期、節次、科目代碼、教師代碼、課堂屬性、是否鎖定、備註 | 主資料表；備註用於辨識同班同科的手動分組 |
| 教師不排課 | 記錄ID、教師代碼、星期、節次、原因 | 教師的封鎖時段 |
| 科目時段規則 | 規則ID、科目代碼、星期、節次、規則類型、備註 | 必排／禁排 |
| 綁班群組 | 群組ID、群組名稱、科目代碼、班級清單 | 多班合上課程 |
| 系統設定 | 設定項、設定值 | 學校名稱、學期代號等 |

## 三、UI 規格
- **主色調**：亮色系，`--bg: #f0f4f8`、`--surface: #ffffff`、`--accent: #2563eb`
- **課表格**：約 54px 高，字 12～13px，overflow ellipsis
- **不排課格**：斜線灰底 `repeating-linear-gradient`
- **下學期預排格**：課表淡色顯示，Word 匯出使用灰色字體，不列入教師鐘點
- **衝突紅框**：`box-shadow: 0 0 0 2px var(--danger) inset`
- **警告黃框**（連堂軟性）：`box-shadow: 0 0 0 2px var(--warning) inset`
- **字體**：Noto Sans TC
